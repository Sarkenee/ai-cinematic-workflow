# Contributing Guidelines

Thanks for your interest in contributing! This project is open to:
- Developers building AI tools, pipelines, or plugins
- Animators or VFX artists helping prototype workflows
- Ethics reviewers and open-source advocates

To get started:
1. Fork the repo
2. Add your module or notes in the appropriate folder
3. Open a Pull Request with a description

Please keep contributions respectful, well-documented, and aligned with the project's focus on human-centered creativity.
